# Carl AI

Carl is a standalone family agent application: its domain model, PostgreSQL records, deterministic capabilities, reasoning, QQQ administration, and workflows form one product. Version 1 reads permitted bills, Apple iCloud/CalDAV calendars, and vendor records, produces reports, and prepares local drafts. It cannot send, book, pay, purchase, or make commitments.

Implementation is in progress. No build, integration, or production qualification is claimed. Start with [requirements](docs/REQUIREMENTS.md), [confirmed decisions](docs/DECISIONS.md), [implementation work](docs/TODO.md), and [acceptance evidence](docs/ACCEPTANCE.md). Development uses synthetic data only. The foundation release pin is awaiting remote artifact qualification.
